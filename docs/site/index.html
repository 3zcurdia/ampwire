Ampwire

Winamp 2's anatomy, a modern hi-fi player in your terminal.

Local lossless files, Jellyfin server streaming, native SMB shares — no kernel mount, no libsmbclient. Keyboard-driven Ratatui TUI.

Install

macOS / Linux (curl):

curl --proto '=https' --tlsv1.2 -LsSf https://3zcurdia.github.io/ampwire/install.sh | sh

Homebrew:

brew install 3zcurdia/tap/ampwire
Pin a version

Set AMPWIRE_VERSION on sh, not on curl:

curl --proto '=https' --tlsv1.2 -LsSf https://3zcurdia.github.io/ampwire/install.sh \ | AMPWIRE_VERSION=0.1.0 sh

Direct from GitHub (fallback): ampwire-installer.sh

Requirements

  • macOS (Apple Silicon or Intel) or Linux with glibc ≥ 2.35.
  • Linux: ALSA runtime (libasound2 / libasound2t64 on Debian/Ubuntu, alsa-lib on Fedora/Arch, alsa on openSUSE).
  • A real TTY; minimum terminal 40×3.
  • Windows is unsupported.

First run

ampwire ~/Music
ampwire smb://nas/Music

j loads a Jellyfin library (if configured), q quits. ampwire --demo runs a no-audio tour. ampwire --help for options.

Verify the download

Checksums ship with every release:

shasum -a 256 -c ampwire-*.tar.xz.sha256 # macOS sha256sum -c ampwire-*.tar.xz.sha256 # Linux

Attestations:

gh attestation verify ampwire-*.tar.xz --repo 3zcurdia/ampwire
