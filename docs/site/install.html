Install

Quick install

curl --proto '=https' --tlsv1.2 -LsSf https://3zcurdia.github.io/ampwire/install.sh | sh
brew install 3zcurdia/tap/ampwire

Requirements

  • macOS (Apple Silicon or Intel) or Linux with glibc ≥ 2.35.
  • Linux: ALSA runtime (libasound2/libasound2t64 on Debian/Ubuntu, alsa-lib on Fedora/Arch, alsa on openSUSE).
  • A real TTY; minimum terminal 40×3.
  • Windows is unsupported.

Upgrade

Re-run the curl command, or:

brew upgrade ampwire

Uninstall

Remove the binary:

rm ~/.local/bin/ampwire

Optionally remove the source "$HOME/.local/bin/env" line from your shell rc. Homebrew:

brew uninstall ampwire

Configuration remains at ~/.config/ampwire/config.toml unless you remove it.

Troubleshooting

  • command not found: ampwire — run source ~/.local/bin/env or restart the shell.
  • Missing libasound.so.2 — install the ALSA runtime (see requirements).
  • glibc too old — your system is below the glibc 2.35 baseline; use a newer distro or build from source.
  • Gatekeeper / quarantine on a browser-downloaded archive — xattr -d com.apple.quarantine <file>.
  • cannot play 96000 Hz — ampwire never resamples; the device does not support that rate.
  • No audio device / terminal too small — see the README.
